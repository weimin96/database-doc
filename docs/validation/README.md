## 实现范围

- Tauri 2 + React + TypeScript 桌面应用，连接 PostgreSQL、Schema 筛选、表搜索、跨 Schema 勾选、字段结构查看和 DOCX 导出。
- 常用连接配置存入应用配置目录；数据库密码与 API 密钥仅在运行期间保存，不落盘。
- Rust 请求用户配置的 OpenAI 兼容 Chat Completions 接口；表结构发送前确认、缺失注释建议、人工编辑和勾选、写回前确认、逐表事务及回读。
- 模型不能执行 SQL；只允许已核验目标的表/字段 COMMENT。锁内重新核对快照，已有注释不覆盖，提交不确定时不自动重放。
- 运行时草稿随连接失效；未写回的建议不进入导出文档。当前无自动目录、自定义模板导入或提交后的自动撤销。
