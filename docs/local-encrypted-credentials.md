# 本地加密数据库密码（替代 Keychain）

2026-10-21。目标：项目进入后自动连接，不依赖 Mac 钥匙串或用户每次输入密码。

- Rust 模块 `src-tauri/src/credentials.rs` 使用 `ring` 的 AES-256-GCM。随机 256-bit 主密钥由系统安全随机数生成，唯一 96-bit nonce 随每次保存重新生成，使用连接 UUID 作为 AAD。保存格式 `DDC1 | nonce | ciphertext | authentication tag`。
- 存储位置：`~/Library/Application Support/com.database-doc.desktop/secrets/`，其中 `master.key` 保存主密钥、`<连接UUID>.enc` 保存加密密码。目录 `0700`，文件 `0600`。使用新的临时文件原子替换密文；Keychain 无运行时调用/依赖。
- 修改密码：使用连接表单成功连接后才保存新的加密密码；未勾选保存则移除该连接密文。连接参数更改时不会以旧密码静默连接不同库或账户。
- 自动连接：打开项目恢复连接 UUID，读取加密密码（只在 Rust 内存中解密），再由 SQLx 连接数据库，返回表结构给前端。找不到密文、损坏或密钥丢失时退回预填连接表单，并明确提示重新输入。
- 首次升级：旧 Keychain 密码不自动读取或迁移；需重新输入一次。历史 Keychain 项不会由当前代码删除。

## 安全边界

此实现针对“避免配置明文存储”和“非同用户直接读取文件”的场景，并不提供独立主口令保护。拥有同一 macOS 用户文件读权限的攻击者如同时读到密钥和密文，可以解密。保护本机用户账户、限制文件共享/备份访问至关重要。转移到另一台 Mac 时必须同时备份密钥和密文，或者重新输入密码。
